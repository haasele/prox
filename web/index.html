      Settings

      How prox handles new containers and host port publishing.

      Routing policy

      Rewrite
      New containers are routed automatically; host bindings are removed.
      Warn
      Containers run unproxied and prox reports a warning.
      Deny
      Containers that publish host ports are rejected.

      Enforcement

      Blocks direct host-port publishing from the raw Docker socket. Docker must be restarted after enabling.

      New rule

      Ports are 1–65535. Leave Gateway port empty to use 443 for HTTP or the source port for TCP. Redirect applies to HTTP allow rules only.
